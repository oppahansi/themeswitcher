## [1.0.0] - 2026-10-26

### Added

- Theme selection with bundled themes, an accent color override and custom CSS, set from the dashboard.
- Stylesheet injection through the File Transformation plugin when it's installed, otherwise into jellyfin-web's `index.html`.
- Builds for Jellyfin 10.9, 10.10, 10.11, 12.0, 12.1, 12.2 and 12.3.
